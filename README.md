# Apsii

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas.

O projeto está sendo construído e evoluído ao longo das aulas, com a implementação e prática dos conceitos apresentados em sala.

## 🎯 Objetivo

Aplicar na prática os conhecimentos adquiridos nas aulas de programação, desenvolvendo gradualmente uma aplicação em Java.

## 🛠️ Tecnologias

- Java
- Git
- GitHub

## 📚 Desenvolvimento

O projeto encontra-se em desenvolvimento e recebe novas implementações conforme os conteúdos são apresentados nas aulas.

A proposta é utilizar o projeto como ambiente de prática para:

- Desenvolvimento em Java
- Lógica de programação
- Programação Orientada a Objetos
- Testes
- Organização de código
- Controle de versão com Git

## 📈 Evolução

O projeto é atualizado continuamente durante as aulas, permitindo acompanhar a evolução do desenvolvimento e a aplicação dos conceitos estudados.

Projeto desenvolvido para fins acadêmicos durante a formação em Análise e Desenvolvimento de Sistemas.
